# RAYLINK

RAYLINK is a privately branded build of [RustDesk](https://github.com/rustdesk/rustdesk) (AGPL-3.0).
Source changes are in this repository, as AGPL requires.

- App name: RAYLINK
- Uses one private ID/relay server only (set in `src/common.rs`, `load_raylink_builtin`)
- Default language: Persian (fa)
- Font: Lateef (SIL Open Font License, `flutter/assets/fonts/Lateef-OFL.txt`)
- Sharp corners in the UI, green #009355 / charcoal #1D2226
